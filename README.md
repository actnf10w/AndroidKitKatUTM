# AndroidKitKatUTM
Run Android-x86’s KitKat system in UTM. Works on all Apple devices with UTM or UTM SE installed.
# Prerequisite 
• Any iOS/iPadOS/MacOS device with UTM or UTM SE installed.(Install Guide)

• Need at least 512MB memory for the VM.

• JIT is not strictly required. But you are recommended to use JIT via Stikdebug and Trollstore etc for a faster performance.
# Installation
Step 1: Everything from prerequisite 

Step 2: Go to UTM settings->touch input->change to touch mode(try hiding curser)

Step 3: Two options

Option 1: Download the *.zip from releases and unzip it into a desired destination in the Files app or UTM folder, you will see a .utm folder there.
