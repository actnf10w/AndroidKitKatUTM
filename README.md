# AndroidKitKatUTM
Run Android-x86’s KitKat system in UTM. Works on all Apple devices with UTM or UTM SE installed.
# Comaptibility
• Any iOS/iPadOS/MacOS device with UTM or UTM SE installed.

• Need at least 512 GB memory for the VM. 
• Jit is not strictly required. Meaning you can also run the VM on UTM SE, with a slower speed than sideloaded UTM app with JIT enabled via Stikdebug, Trollstore etc.
